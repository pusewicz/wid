# E0209: `self` or `@field` outside a method

`self` and `@field` refer to the receiver of a method, so they only exist
inside the methods of a `struct`, `enum`, `module` or `extend` block, and
`Self` (the receiver's type) only inside those blocks. A package-level `def`
has no receiver. Neither does a type-level method (`def self.name`), which is
called on the type rather than on a value. The same code reports
`def self.name` written outside a type, where there is no type for `self` to
name.

A macro's own code may use `Self` too: it is the type whose body or method
holds the macro call, so a macro called in a `struct` body can read
`Self.fields`. A call of such a macro is this error where there is no such
type (at package level, or in a method that isn't a type's), and where `Self`
stands for many types: in a `module` or `extend` body, and in a generic
struct's body, where the macro runs once for every instance.

## Example

```wid
struct Counter
  value: Int
end

def bump
  @value += 1
end

def main
  bump
end
```

```text
error[E0209]: `@value` only exists inside a method of a type
 --> main.wid:6:3
  |
6 |   @value += 1
  |   ^^^^^^ there is no receiver here
help: define this method inside a `struct` or `enum` to use `self` and `@fields`
  = see `wid explain E0209`
```

## How to fix

- Move the method into the type's body. There, `@value` means `self.value`.
- Or keep it at package level and take the value as a parameter:
  `def bump(c: ^Counter)`, then `c.value += 1`, called as `bump(&c)`.
- In a `def self.name` method, remove `self.` from the name to make it an
  instance method, or work on a value passed as a parameter.
- Outside a type, write `def name` instead of `def self.name`.

```wid
struct Counter
  value: Int

  def bump
    @value += 1
  end
end

def main
  c = Counter.new
  c.bump
  puts c.value
end
```

## A macro that uses `Self`

The macro generates a method that names the type it is called in, but the
call is at package level:

```wid
macro def type_namer -> Code
  name = Self.name
  quote do
    def type_name -> String = #{name}
  end
end

type_namer

def main
end
```

```text
error[E0209]: `type_namer` needs a `Self`, but this call has none
 --> main.wid:8:1
  |
2 |   name = Self.name
  |          ---- the macro's code uses `Self` here
...
8 | type_namer
  | ^^^^^^^^^^ `type_namer` expands here, outside any type
  = note: a macro's `Self` is the type whose body or method holds the call
help: call `type_namer` in the body or a method of a `struct` or `enum`, or give the macro a `Type` parameter and pass the type
  = see `wid explain E0209`
```

Call it in the body of the type it describes, or give the macro a `Type`
parameter and pass the type:

```wid
macro def type_namer -> Code
  name = Self.name
  quote do
    def type_name -> String = #{name}
  end
end

struct Ship
  speed: Int
  type_namer
end

def main
  puts Ship.new(speed: 1).type_name
end
```
