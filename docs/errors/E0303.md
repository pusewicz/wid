# E0303: unknown or duplicate named argument

A call passes an argument by a name the method does not have, or passes the
same parameter twice. Any parameter can be passed by name, but the name must
match the definition exactly. When a parameter has a similar name, the error
suggests it; otherwise the note lists the parameters.

The same code covers other named arguments that don't fit: an unknown or
repeated field in `Type.new(…)`, any named argument to `puts`, `print`, `p`,
a proc or an `overload` set, and `import` options other than `as:`.

## Example

```wid
def area(width: Int, height: Int) -> Int
  width * height
end

def main
  puts area(width: 3, heigth: 4)
end
```

```text
error[E0303]: `area` has no parameter named `heigth`
 --> main.wid:6:23
  |
6 |   puts area(width: 3, heigth: 4)
  |                       ^^^^^^ unknown parameter
help: did you mean `height`?
  |   puts area(width: 3, height: 4)
  = see `wid explain E0303`
```

## How to fix

- Use the parameter names from the definition.
- Pass each parameter once. A positional argument already fills a parameter,
  so `area(3, width: 4)` gives `width` twice.
- Pass arguments to procs, `overload` sets, `puts`, `print` and `p` by
  position.
- `import` accepts only `as:`.

```wid
def area(width: Int, height: Int) -> Int
  width * height
end

def main
  puts area(width: 3, height: 4)
end
```
