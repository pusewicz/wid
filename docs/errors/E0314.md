# E0314: unknown type

A type annotation names a type that is not in scope. Type names start with an
uppercase letter and are case-sensitive. Wid's primitives have short names
(`Int`, `F32`, `Bool`, `String`), and types from other packages are written
`package.Type`. When a type with a similar name exists, the error suggests it.
When the name looks like one from another language, the help gives the Wid
equivalent.

The same code reports `$T` used where it does not introduce a type parameter,
such as in a return type, and type paths with more than one `.`.

## Example

```wid
def main
  x: Integer = 1
  name: Strng = "Ada"
  puts x
  puts name
end
```

```text
error[E0314]: unknown type `Integer`
 --> main.wid:2:6
  |
2 |   x: Integer = 1
  |      ^^^^^^^ no type with this name is in scope
help: Wid's default integer type is `Int`
  = see `wid explain E0314`

error[E0314]: unknown type `Strng`
 --> main.wid:3:9
  |
3 |   name: Strng = "Ada"
  |         ^^^^^ no type with this name is in scope
help: a similar type exists: `String`
  |   name: String = "Ada"
  = see `wid explain E0314`
```

## How to fix

- Fix the spelling, or use Wid's name: `Int` (not `Integer`), `F32` or `F64`
  (not `Float` or `double`), `Bool`, `String`, `[N]T`, `[]T` or `[dynamic]T`
  (not `Array`), `map[K]V` (not `Hash`).
- For a type from another package, import it and qualify the name:
  `rl.Texture`.
- Define the type if it doesn't exist yet: `struct Player … end`, or an alias
  constant such as `Vec2 = [2]F32`.
- Type parameters are introduced with `$` in a parameter and then used
  without it: `def max(a: $T, b: T) -> T`.

```wid
def main
  x: Int = 1
  name: String = "Ada"
  puts x
  puts name
end
```
