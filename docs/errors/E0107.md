# E0107: invalid assignment target

The left side of `=` or of a compound assignment like `+=` cannot hold a value.
Only a variable, a field (`ball.pos`, `@pos`), an index (`grid[i]`) or a
dereference (`p^`) can be assigned. Constants get their value once, where they
are declared, and a safe-navigation field (`x&.field`) may not exist, so
neither can be assigned. A method call returns a temporary value, which has
nowhere to store into.

The same code covers two related slips: `=` written where `==` was meant in a
condition (`if a + 1 = 2`, fixed by writing `==`), and a compound assignment
with several targets (`a, b += 1`), which must be split into one statement per
target.

## Example

```wid
def main
  width = 4
  height = 3
  width * height = 12
  puts width
  puts height
end
```

```text
error[E0107]: cannot assign to this expression
 --> main.wid:4:3
  |
4 |   width * height = 12
  |   ^^^^^^^^^^^^^^ not a variable, field or index
  |                  - assignment here
  = note: only variables, fields (`a.b`), indexes (`a[i]`) and dereferences (`p^`) can be assigned
  = see `wid explain E0107`
```

The E0001 is a side effect of the same mistake. Fixing the assignment fixes
both.

## How to fix

- To compare, use `==`.
- To store a result, put a variable on the left: `area = width * height`.
- Constants (names that start with an uppercase letter) are fixed at compile
  time and cannot be assigned inside a method. Use a lowercase variable.
- `x&.field = …` is not allowed. Check the optional first: inside `if x … end`,
  `x` is narrowed and `x.field = …` works.

```wid
def main
  width = 4
  height = 3
  area = width * height
  puts area == 12
end
```
