# E0703: invalid `cimport` option

A `cimport` option is unknown, given twice, or has a value of the wrong kind.
The options are:

- `as: :name`: the namespace (without it, the names join the package's own);
- `strip_prefix: "lib_"` (or an array): prefixes removed from every name;
- `rename: :snake_case` (default) or `:keep`: how function and field names
  are spelled;
- `names: {CName: :wid_name}`: the Wid name of single declarations;
- `types: {CStruct: WidType}`: Wid types that stand in for C structs;
- `define: ["NAME=value"]`, `implement: "NAME"`, `link: ["lib"]`,
  `pkg_config: "lib"` and `include_dirs: ["dir"]`.

The same code reports a `types:` key that names no struct or union in the
header.

## Example

`sound.h`:

```c
void snd_play(int id);
```

`main.wid`:

```wid
cimport "sound.h", as: :snd, strip_prefixes: "snd_"

def main
  snd.play(1)
end
```

```text
error[E0703]: `cimport` has no option `strip_prefixes:`
 --> main.wid:1:30
  |
1 | cimport "sound.h", as: :snd, strip_prefixes: "snd_"
  |                              ^^^^^^^^^^^^^^ unknown option
help: did you mean `strip_prefix:`?
  | cimport "sound.h", as: :snd, strip_prefix: "snd_"
  = see `wid explain E0703`
```

## How to fix

Use one of the options above, with the value it takes:

```wid
cimport "sound.h", as: :snd, strip_prefix: "snd_"

def main
  snd.play(1)
end
```
