# E0331: symbol where an enum member is expected

An enum member is written `.name`, as in Odin and Swift: `d: Dir = .North`,
`when .North then …`, `go(.South)`, `return {}, .NotFound`. Where an enum
(or `Error`) is expected, the member is looked up in that enum.

A symbol, `:name`, is something else: a compile-time name that macros take
(`counter :hits`), splice and compare, and that `method(:on_hit)`,
`config(:debug_draw, false)` and `cimport` options read. A symbol where an
enum member goes is this error; its fix writes the `.`. A symbol stored in
a variable, or used anywhere else a run-time value goes, is this error too:
it names nothing the running program can hold.

## Example

```wid
enum Dir
  North
  South
end

def main
  heading: Dir = :north
  p heading == :south
end
```

```text
error[E0331]: an enum member is written `.North`, not `:north`
 --> main.wid:7:18
  |
7 |   heading: Dir = :north
  |                  ^^^^^^ a member of `Dir` goes here
  = note: `:name` is a symbol, a name for macros and options; `.name` is a member of the enum expected
help: write `.North`
  |   heading: Dir = .North
  = see `wid explain E0331`

error[E0331]: an enum member is written `.South`, not `:south`
 --> main.wid:8:16
  |
8 |   p heading == :south
  |                ^^^^^^ a member of `Dir` goes here
  = note: `:name` is a symbol, a name for macros and options; `.name` is a member of the enum expected
help: write `.South`
  |   p heading == .South
  = see `wid explain E0331`
```

A macro whose `quote` writes `:#{name}` where a member goes gets the same
error, without a fix at the call: the macro writes `.#{name}` instead.

## How to fix

- Write the member with a `.`: `.North`. Where no enum is expected, name
  the enum: `Dir.North`.
- In a `quote`, splice a member from a `Symbol` with `.#{name}` (or
  `[.#{names}]` for a list).

```wid
enum Dir
  North
  South
end

def main
  heading: Dir = .North
  p heading == .South
end
```
