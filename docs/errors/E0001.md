# E0001: feature not implemented yet

The program uses a feature that `SPEC.md` describes but this version of the
compiler does not support yet. Your code may be valid Wid; the compiler stops
because it cannot check or generate code for that feature. The message names
the feature.

No construct reports E0001 at the moment: every feature the compiler does not
implement yet has its own code with a workaround, such as E0701 for
`cimport` and E0901 for `comptime`. The code stays reserved for features that
are added to the spec before the compiler supports them.

## How to fix

- Check `docs/STATUS.md` in the Wid repository. It lists what the compiler
  implements and what comes next.
- Rewrite the code with features that already work.
- If `docs/STATUS.md` lists the feature as done and you still get E0001,
  report it as a compiler bug.
