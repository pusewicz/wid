# E0322: expected a type

A type is required here, but the code gives something else, such as a
constant value or a method. Types appear in annotations (`x: T`), parameter,
return and field types, `.to(T)`, and type arguments like `alloc(T)` and
`size_of(T)`.

The same code reports a local variable used as a type (`b: n = 4`, with a fix
that writes the variable's type), a generic struct's value parameter used as
a type (`x: N` in a method of `Pool($T, $N: Int)`, with a fix that writes
`Int`), an unnamed `distinct` type (`x: distinct F64`; declare
`Meters = distinct F64` and use `Meters`), and `include` of something that is
not a module.

## Example

```wid
MAX = 10

def main
  x: MAX = 3
  puts x
end
```

```text
error[E0322]: `MAX` is a constant, not a type
 --> main.wid:4:6
  |
4 |   x: MAX = 3
  |      ^^^ expected a type here
help: types are primitives like `Int`, structs, enums, unions, and constants like `Meters = distinct F64`
  = see `wid explain E0322`
```

## How to fix

- Write a type: `x: Int = 3`.
- To name a type, assign a type to a constant: `Score = Int`,
  `Vec2 = [2]F32`. Such a constant can then be used as a type.
- `distinct` creates a new named type, so it is only written as a
  constant's value: declare `Meters = distinct F64` and write `x: Meters`,
  not `x: distinct F64`.
- `.to`, `alloc` and `size_of` take a type, not a value: `n.to(F32)`. For a
  variable, write its type (`size_of(Int)` rather than `size_of(count)`; the
  fix offers it). Any type can be written there, like `size_of(Int?)` or
  `align_of(proc(Int) -> Int)`.

```wid
MAX = 10

def main
  x: Int = 3
  puts x + MAX
end
```

## `include` of something that is not a module

`include` mixes in the methods of a `module … end`. Including a struct, enum
or other declaration is the same error:

```wid
struct Entity
  hp: Int
end

struct Robot
  include Entity
end

def main
  p Robot.new
end
```

```text
error[E0322]: `include` takes a module, but this is a struct
 --> main.wid:6:11
  |
1 | struct Entity
  |        ------ the struct is declared here
...
6 |   include Entity
  |           ^^^^^^ not a module
help: to reuse a struct's fields and methods, add a `using` field instead
  |   using entity: Entity
  = see `wid explain E0322`
```

A `using` field embeds the other struct and promotes its fields and methods.
To share only methods, move them into a `module` and include that.

## A value parameter used as a type

In `struct Pool($T, $N: Int)`, `N` is a constant of each instance (`4` in
`Pool(Int, 4)`), not a type, in the struct's fields, its methods and their
signatures:

```wid
struct Pool($T, $N: Int)
  items: [N]T

  def first_index -> N = 0
end

def main
  pool: Pool(Int, 4) = {}
  p pool.first_index
end
```

```text
error[E0322]: `N` is a value, not a type
 --> main.wid:4:22
  |
1 | struct Pool($T, $N: Int)
  |                 ------- `N` is a value parameter, a constant `Int`
...
4 |   def first_index -> N = 0
  |                      ^ expected a type here
  = note: a value parameter is a constant: it can be an array length, like `[N]T`, or a value, like `N.times`
help: for the type of `N`, write `Int`
  |   def first_index -> Int = 0
  = see `wid explain E0322`
```

Write the type the value has, `Int`, and use `N` where a constant fits: as
an array length (`[N]T`) or a value (`N - 1`, `N.times`).
