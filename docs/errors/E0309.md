# E0309: cannot assign to this expression

The assignment target looks like a field or an index, but it does not name
storage that outlives the statement. The usual case is a field of a value
returned by a call. Struct values are copied, so the call returns a temporary
copy and the assignment would change nothing. E0107 covers targets that can
never be assigned by their shape, such as `a + b = c`.

The same code reports other changes to values that can't be changed: `&` of
a temporary, `<<` or a method such as `push` on a temporary container, a store
into a temporary map, a byte of a `String`, and `x[i] = v` on a type without
a `[]=` method.

## Example

```wid
struct Ball
  pos: [2]F32
end

def spawn -> Ball = Ball.new(pos: [0.0, 0.0])

def main
  spawn.pos = [1.0, 2.0]
end
```

```text
error[E0309]: cannot assign to this expression
 --> main.wid:8:3
  |
8 |   spawn.pos = [1.0, 2.0]
  |   ^^^^^^^^^ this is a temporary value, not a variable or field
help: store the value in a variable first, change it, and use the variable
  = see `wid explain E0309`
```

## How to fix

- Store the value in a variable, then assign to its field: `ball = spawn`,
  then `ball.pos = …`.
- To change data in place through a method, pass or return a pointer (`^Ball`)
  instead of a value.
- `String` is an immutable view, so its bytes cannot be assigned. Build a new
  string instead, for example with interpolation.

```wid
struct Ball
  pos: [2]F32
end

def spawn -> Ball = Ball.new(pos: [0.0, 0.0])

def main
  ball = spawn
  ball.pos = [1.0, 2.0]
  p ball
end
```

## Assigning through `[]` on a struct

`x[i] = v` on a struct or enum calls its `[]=` method, and `x[i] += v` calls
`[]` to read the old value and then `[]=` to store the new one. Without the
method there is nothing to assign through:

```wid
struct Lookup
  def [](i: Int) -> Int = i
end

def main
  l = Lookup.new
  l[0] = 1
end
```

```text
error[E0309]: `Lookup` has no `[]=` method
 --> main.wid:7:3
  |
7 |   l[0] = 1
  |   ^^^^ cannot assign through this index
help: define `def []=(index: Int, value: T)` in `Lookup` to support `x[i] = value`
  = see `wid explain E0309`
```

Define `def []=(i: Int, v: Int)` on the struct, or assign to the field that
holds the data.
