# E0324: missing return value

A method declares a return type, but some path reaches its end without a
value. A method's last expression is its value, and an `if` without `else`
has no value when its condition is false.

The same code reports a proc literal with `-> R` that can reach its end
without a value, and an `if` without `else` whose value is assigned to a
variable.

## Example

```wid
def sign(n: Int) -> Int
  if n > 0
    return 1
  end
end

def main
  puts sign(3)
end
```

```text
error[E0324]: `sign` must return `Int`
 --> main.wid:2:3
  |
1 | def sign(n: Int) -> Int
  | ----------------------- declared to return `Int` here
2 |   if n > 0
  |   ^^^^^^^^ the method can reach its end without a value
help: make the last expression the value to return, or add an explicit `return`
  = see `wid explain E0324`
```

## How to fix

- End the method with an expression or a `return` that covers the remaining
  paths.
- Give the `if` an `else`, so every branch produces a value.
- If a path truly cannot happen, mark it with `unreachable` or `panic`.

```wid
def sign(n: Int) -> Int
  if n > 0
    1
  elsif n < 0
    -1
  else
    0
  end
end

def main
  puts sign(3)
end
```
