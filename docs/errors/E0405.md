# E0405: control flow leaves a `defer`

A `defer` body uses `return`, `break` or `next` to jump out of itself.
Deferred code runs while its scope is already exiting, for example during a
`return`, so jumping elsewhere from it would leave that exit half done. A
`defer` body must run to its end. A loop entirely inside the `defer` body can
still use `break` and `next`.

## Example

```wid
def close_all(count: Int)
  defer do
    return if count == 0
    puts count
  end
  puts "working"
end

def main
  close_all(2)
end
```

```text
error[E0405]: `return` cannot leave a `defer` body
 --> main.wid:3:5
  |
3 |     return if count == 0
  |     ^^^^^^ deferred code must run to completion
  = note: `defer` runs while the scope is already exiting, so it cannot jump elsewhere
help: instead of `return`, wrap the rest of the deferred code in an `if`
  = see `wid explain E0405`
```

## How to fix

- Turn the early exit into a condition around the rest of the body:
  `puts count if count > 0`.
- Decide before the `defer` statement, and defer only the cleanup that must
  always run.

```wid
def close_all(count: Int)
  defer do
    puts count if count > 0
  end
  puts "working"
end

def main
  close_all(2)
end
```
