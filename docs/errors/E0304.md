# E0304: type cannot be inferred

The compiler needs a type for a value, and nothing in the code says which one.
A variable takes its type from its first value, so that value must have a
concrete type. `nil` alone could be any optional, `{}` could be the zero value
of any type, a symbol like `:north` could belong to any enum, and an empty `[]`
has no element to take a type from.

## Example

```wid
def main
  target = nil
  puts target
end
```

```text
error[E0304]: cannot infer the type of `nil`
 --> main.wid:2:12
  |
2 |   target = nil
  |            ^^^ `nil` alone doesn't say which optional type this is
help: declare the type, like `x: Int? = nil`
  = see `wid explain E0304`
```

## How to fix

- Declare the type: `target: Int? = nil`, `pos: Vec2 = {}`,
  `dir: Dir = :north`, `xs: [0]Int = []`.
- Or build the value with its type: `Ball.new` instead of `{}`, `Dir.north`
  instead of `:north`, `[dynamic]Int.new` for a growable array.
- Where a type is already expected, such as an argument, a field or a return
  value, `nil`, `{}` and symbols need no annotation.

```wid
def main
  target: Int? = nil
  puts target || 0
end
```
