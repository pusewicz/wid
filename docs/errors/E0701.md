# E0701: C header import failed

`cimport` reads a C header with libclang and turns its functions, structs,
unions, enums, typedefs, constants and simple macros into a Wid package. The
import fails when:

- the header is not found: a path is looked up next to the package's files
  first, then on the include path (`include_dirs:`, the flags from
  `pkg_config:`, and the system headers), like `#include <name>`;
- the header does not parse: clang's errors are shown at their place in the
  header;
- libclang is not installed, or is too old to use;
- `pkg_config:` names a package pkg-config doesn't know.

## Example

`sprite.h`:

```c
void sprite_draw(int id);
```

`main.wid`:

```wid
cimport "sprit.h", as: :sprite, strip_prefix: "sprite_"

def main
  sprite.draw(1)
end
```

```text
error[E0701]: header `sprit.h` not found
 --> main.wid:1:9
  |
1 | cimport "sprit.h", as: :sprite, strip_prefix: "sprite_"
  |         ^^^^^^^^^ not next to the package's files or on the include path
help: write the path relative to the package directory, add its directory with `include_dirs:`, or name the library with `pkg_config:`
  = see `wid explain E0701`
```

## How to fix

- Check the spelling and the path. A header in the package directory is
  written relative to it: `cimport "vendor/stb_image.h"`.
- For a library installed elsewhere, add its directory with
  `include_dirs: ["path/to/include"]` or use `pkg_config: "name"`.
- If the header expects configuration macros, set them with `define:`.
- If libclang is missing, install LLVM (for example `brew install llvm` or
  `apt install libclang-dev`) or point `LIBCLANG_PATH` at it. Only `cimport`
  needs libclang.
- C++ headers can't be imported. Go through a C API (`extern "C"`), as
  cimgui does for Dear ImGui.

```wid
cimport "sprite.h", as: :sprite, strip_prefix: "sprite_"

def main
  sprite.draw(1)
end
```
