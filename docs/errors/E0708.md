# E0708: C variadic arguments misused

C functions that end in `...`, like `printf`, receive their extra arguments
the C way. Wid passes numbers, pointers, C strings and C structs there;
untyped integer literals become `C.int` and float literals `C.double`, as in
C. A `String`, slice, dynamic array or map is not a C value, so it can't be
passed.

The same code reports `...` on a method that isn't `@[extern]`: only C code
can read C variadic arguments.

## Example

`main.wid`:

```wid
cimport "stdio.h", as: :cio

def main
  name = "Ada"
  cio.printf("hello, %s\n", name)
end
```

```text
error[E0708]: `String` can't be passed through C's `...`
 --> main.wid:5:29
  |
5 |   cio.printf("hello, %s\n", name)
  |                             ^^^^ this is `String`
  = note: C variadic arguments take numbers, pointers, C strings and C structs
help: pass a C string
  |   cio.printf("hello, %s\n", name.to_cstr)
  = see `wid explain E0708`
```

## How to fix

Convert the value to something C understands, like a C string:

```wid
cimport "stdio.h", as: :cio

def main
  name = "Ada"
  cio.printf("hello, %s\n", name.to_cstr)
end
```

For a Wid method that takes any number of values, use a `*rest: T`
parameter instead of `...`.
