# E0404: `break` or `next` outside a loop

`break` leaves the innermost loop and `next` skips to its next iteration, but
this statement is not inside a `while`, `until`, `for` or `loop`, nor inside a
block passed to a method, where `break` and `next` work as in Ruby. A proc body
is neither, so `break` and `next` need a loop there too. To leave a method
early, use `return`.

## Example

```wid
def main
  break
end
```

```text
error[E0404]: `break` outside of a loop or block
 --> main.wid:2:3
  |
2 |   break
  |   ^^^^^ there is no loop or block to leave
help: to leave the method early, use `return`
  = see `wid explain E0404`
```

For `next`, the label reads "there is no loop or block to continue".

## How to fix

- To leave the method, use `return`.
- Make sure the statement is inside the loop you meant. A misplaced `end` can
  close the loop too early and leave the `break` outside it.
- `break` and `next` also cannot jump out of a `defer` body (E0405).

```wid
def main
  for i in 0...10
    break if i == 3
    puts i
  end
end
```
