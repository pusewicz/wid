# E0904: compile-time code called C

Compile-time code called a function implemented in C: an `@[extern]` method or
a function from a `cimport`ed header. C code is compiled into the program, so it
doesn't exist yet while the compiler runs, and the compiler can't run it.

The pure math functions of `core:math` (`sqrt`, `sin`, `pow` and the rest) and
`core`'s memory helpers are the exception: the compiler implements them itself,
so they work in `comptime`.

## Example

```wid
@[extern("fast_noise")]
def noise(x: F64) -> F64
end

def sample -> F64 = noise(0.5)

NOISE = comptime sample

def main
  puts NOISE
end
```

```text
error[E0904]: `comptime` code can't call C: it calls `noise`, which is implemented in C (`fast_noise`) and only runs in the built program
 --> main.wid:5:5
  |
5 | def sample -> F64 = noise(0.5)
  |     ^^^^^^ failed here
...
7 | NOISE = comptime sample
  |         --------------- while running this at compile time
help: compute the value at run time instead, or write the computation in Wid
  = see `wid explain E0904`
```

## How to fix

Compute the value when the program runs, or write the computation in Wid:

```wid
@[extern("fast_noise")]
def noise(x: F64) -> F64
end

def main
  puts 0.5 * 0.5
end
```
