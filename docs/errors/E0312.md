# E0312: type contains itself

A struct contains itself by value, directly or through other structs or fixed
arrays. Struct values are stored inline and copied, so such a type would need
infinite size. The same applies to generic structs, and to a union whose
variants contain the union by value. A module that includes itself gets the
same code. Types that reach each other only through pointers, slices, dynamic
arrays, maps or procs are fine, because those have a fixed size.

The same code reports a constant whose value depends on itself, like
`A = A + 1`, or `A = B` with `B = A`; the error names every constant on the
cycle.

## Example

```wid
struct Node
  value: Int
  parent: Node
end

def main
  n = Node.new
  p n
end
```

```text
error[E0312]: `Node` contains itself
 --> main.wid:3:3
  |
3 |   parent: Node
  |   ^^^^^^ this field stores a `Node` by value
  = note: `Node` would need to contain a full copy of itself, so it has no finite size
help: store a pointer instead
  |   parent: ^Node
  = see `wid explain E0312`
```

## How to fix

- Store a pointer, which has a fixed size. Pointers can't be nil unless written
  `^T?`, so use `^Node?` when the link can be empty, as for a root node.
- For many children, use a growable array: `children: [dynamic]Node`. Its
  elements live in allocated memory, not inside the struct.
- For a union, make the variant that contains it a pointer:
  `union Expr = Lit | ^Neg`.
- Remove an `include` of the module from its own body.

```wid
struct Node
  value: Int
  parent: ^Node?
end

def main
  n = Node.new
  p n
end
```
