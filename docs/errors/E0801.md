# E0801: test has the wrong signature

A method marked `@[test]` must be a package-level `def` that takes a
`^testing.T` and returns nothing. `wid test` builds a `main` that calls each
test with a `testing.T`, which records failed expectations, so it has no other
way to call a test.

## Example

```wid
import "core:testing"

@[test]
def adds -> Bool
  1 + 1 == 2
end
```

```text
error[E0801]: test `adds` has the wrong signature
 --> main.wid:4:1
  |
4 | def adds -> Bool
  | ^^^^^^^^^^^^^^^^ a test takes `^testing.T` and returns nothing
  = note: `wid test` calls each `@[test]` method with a `^testing.T` that records failures
help: use the test signature
  | def adds(t: ^testing.T)
  = see `wid explain E0801`
```

## How to fix

- Take one `t: ^testing.T` parameter and report through it instead of
  returning a value:

  ```wid
  @[test]
  def adds(t: ^testing.T)
    t.expect_eq(1 + 1, 2)
  end
  ```

- Import `core:testing` in the file, so `testing.T` names the right type.
- Move tests out of structs, enums and modules: tests are package-level
  methods. Put them in a file ending in `_test.wid`, which only `wid test`
  compiles.
