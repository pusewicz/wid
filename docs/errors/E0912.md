# E0912: macro argument of the wrong kind

A macro receives each argument according to its parameter's type, before
any of the program runs:

- a `Code` parameter receives the argument's code, unevaluated;
- a `Symbol` parameter receives a name, written as a symbol literal (`:hp`);
- a `Type` parameter receives a type (`Int`, `Vec2`, `[]String`);
- any other parameter receives a value computed while compiling, like
  `comptime`.

An argument that is not a symbol literal for a `Symbol` parameter, or not a
type for a `Type` parameter, can't be converted, so the macro can't run.

## Example

```wid
macro def name_of(name: Symbol) -> Code
  quote do
    #{name.to_s}
  end
end

def main
  puts name_of(hits)
end
```

```text
error[E0912]: the macro `name_of` takes a symbol for `name`
 --> main.wid:8:16
  |
1 | macro def name_of(name: Symbol) -> Code
  |                   ------------ `name` is a `Symbol` parameter
...
8 |   puts name_of(hits)
  |                ^^^^ this is not a symbol literal
  = note: a `Symbol` parameter receives a name written as a symbol literal, like `:hp`, not the value of an expression
help: pass the name `hits` as a symbol
  |   puts name_of(:hits)
  = see `wid explain E0912`
```

## How to fix

Write the name as a symbol literal:

```wid
macro def name_of(name: Symbol) -> Code
  quote do
    #{name.to_s}
  end
end

def main
  puts name_of(:hits)
end
```

To compute a name inside the macro, take a `String` and turn it into a
`Symbol` with `.to_sym`. A `Type` parameter takes a type the same way: write
the type itself, like `zero(Int)`.
