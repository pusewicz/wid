# E0108: statement outside a method

Wid runs no code at the top level of a file. A file holds only declarations:
`def`, `struct`, `enum`, `union`, `module`, `extend`, `overload`, `import` and
constants. Calls, loops and variable assignments must be inside a method. The
program starts at `def main`. The same code reports an `include` outside a
type.

## Example

```wid
puts "hello"
x = 1

def main
end
```

```text
error[E0108]: statements must be inside a method
 --> main.wid:1:1
  |
1 | puts "hello"
  | ^^^^^^^^^^^^ this call is outside any `def`
help: move it into `def main … end`, which runs when the program starts
  = see `wid explain E0108`

error[E0108]: statements must be inside a method
 --> main.wid:2:1
  |
2 | x = 1
  | ^^^^^ this statement is outside any `def`
help: move it into `def main … end`, which runs when the program starts
  = see `wid explain E0108`
```

## How to fix

- Move the statements into `def main`, or into a method that `main` calls.
- For a value that never changes, declare a constant instead. A name that
  starts with an uppercase letter is a compile-time constant: `START = 1`.
- Fields go inside a `struct`, and `include` goes inside a `struct`, `enum`,
  `module` or `extend`.

```wid
START = 1

def main
  puts "hello"
  x = START
  puts x
end
```
