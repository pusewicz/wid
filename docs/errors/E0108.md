# E0108: statement outside a method

Wid runs no code at the top level of a file. A file holds only declarations:
`def`, `struct`, `enum`, `union`, `module`, `extend`, `overload`, `import` and
constants. Calls, loops and variable assignments must be inside a method. The
program starts at `def main`. The same code reports an `include` outside a
type.

A call among declarations may only call a macro, whose generated declarations
take its place (`describer :hp`); calling a method there is this error. So is
a statement in the code that a macro called among declarations generates: it
is reported in the macro's `quote`, with the call that generated it.

## Example

```wid
puts "hello"
x = 1

def main
end
```

```text
error[E0108]: statements must be inside a method
 --> main.wid:1:1
  |
1 | puts "hello"
  | ^^^^^^^^^^^^ this call is outside any `def`
help: move it into `def main … end`, which runs when the program starts
  = see `wid explain E0108`

error[E0108]: statements must be inside a method
 --> main.wid:2:1
  |
2 | x = 1
  | ^^^^^ this statement is outside any `def`
help: move it into `def main … end`, which runs when the program starts
  = see `wid explain E0108`
```

## How to fix

- Move the statements into `def main`, or into a method that `main` calls.
- For a value that never changes, declare a constant instead. A name that
  starts with an uppercase letter is a compile-time constant: `START = 1`.
- Fields go inside a `struct`, and `include` goes inside a `struct`, `enum`,
  `module` or `extend`.

```wid
START = 1

def main
  puts "hello"
  x = START
  puts x
end
```

## Statements a macro generates among declarations

The macro is called at package level, so the code it generates must be
declarations, but it generates an assignment:

```wid
macro def start_count -> Code
  quote do
    count = 0
  end
end

start_count

def main
end
```

```text
error[E0108]: statements must be inside a method
 --> main.wid:3:5
  |
3 |     count = 0
  |     ^^^^^^^^^ this statement is outside any `def`
 ::: main.wid:7:1
  |
7 | start_count
  | ----------- `start_count` expands here
  = note: `start_count` is called among declarations, so its code must be declarations: methods, constants, types, `include`s or macro calls
help: put the statement inside a `def` in the `quote`, or call `start_count` inside a method
  = see `wid explain E0108`
```

Generate a constant (its name starts with an uppercase letter) or a method
instead, or call the macro inside a method, where its code runs as
statements:

```wid
macro def start_count -> Code
  quote do
    START = 0
  end
end

start_count

def main
  puts START
end
```
