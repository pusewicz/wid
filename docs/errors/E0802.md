# E0802: test failed

`wid test` reports this for each problem a test ran into:

- an expectation failed (`t.expect`, `t.expect_eq`, `t.fail`, …); the error
  points at the call and shows its message;
- the test panicked; the error points at the panic;
- the test leaked memory: every block the test allocated with
  `context.allocator` and did not free fails the test, pointing at the
  allocation.

Each test runs in its own process on a fresh tracking allocator, so a panic
or a leak only fails that test. Anything the test printed is shown after its
failures.

## Example

```wid
import "core:testing"

@[test]
def adds(t: ^testing.T)
  t.expect_eq(1 + 1, 3)
end
```

```text
running 1 test
test adds ... FAILED

failures:

error[E0802]: test `adds` failed
 --> main.wid:5:3
  |
4 | def adds(t: ^testing.T)
  |     ---- in this test
5 |   t.expect_eq(1 + 1, 3)
  |   ^^^^^^^^^^^^^^^^^^^^^ expected 3, got 2
  = see `wid explain E0802`

test result: FAILED. 0 passed; 1 failed; 0 filtered out
```

## How to fix

- For a failed expectation, fix the code under test, or the expectation if
  the expected value was wrong.
- For a leak, `free` the block, usually with a `defer` right after the
  allocation, or allocate it from `context.temp_allocator` when it only lives
  for a moment.
- For a panic, read its message: bounds, nil and overflow checks name the
  value that was wrong.
- Run a single test with `wid test -filter:adds` while you work on it, and add
  `-json-errors` to get the results as JSON.
