# E0325: yielding method calls itself

A method that takes a block calls itself, directly or through other methods
that take blocks. Blocks are inlined: every call of a method with a block is
expanded into its caller together with the block, which is why blocks cost
nothing and can use locals. A recursive call would need an endless expansion,
so Wid rejects it. The same code reports a chain of block methods inlined into
each other more deeply than the compiler allows.

## Example

```wid
def countdown(n: Int, &blk: block(Int))
  return if n == 0
  yield n
  countdown(n - 1) { |i| yield i }
end

def main
  countdown(3) { |i| puts i }
end
```

```text
error[E0325]: `countdown` takes a block and calls itself
 --> main.wid:4:3
  |
4 |   countdown(n - 1) { |i| yield i }
  |   ^^^^^^^^^ methods with blocks are inlined at each call, so they cannot recurse
help: move the recursion into a helper method without a block, or loop instead
  = see `wid explain E0325`
```

## How to fix

- Rewrite the recursion as a loop. Most recursive walks become a `while` with
  a counter or an explicit stack.
- Or take a `proc` parameter instead of a block. A proc is called through a
  pointer, so recursion works, but it cannot capture locals (E0318).
- Or split the work: a recursive helper without a block that collects results,
  and a method with a block that loops over them.

```wid
def countdown(n: Int, &blk: block(Int))
  i = n
  while i > 0
    yield i
    i -= 1
  end
end

def main
  countdown(3) { |i| puts i }
end
```
