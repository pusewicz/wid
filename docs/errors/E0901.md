# E0901: compile-time evaluation failed

Code run at compile time stopped with an error. `comptime` runs ordinary Wid
code inside the compiler, for example to build a lookup table
(`SIN = comptime build_table(256)`), and constants are computed the same way.
That code always runs with the checks of a `-debug` build, so an out-of-bounds
index, a nil dereference, an integer overflow, a failed `assert` or a `panic`
stops the build here instead of stopping the program later.

The error points at the line that failed, marks the `comptime` that started the
evaluation, and marks each call on the way.

A `macro def` runs the same way, once for each call, so a macro that fails
while it runs (for example an `assert` that rejects its arguments) is
reported here too, at the call.

## Example

A table size computed at compile time from a bad argument:

```wid
def table_size(levels: Int) -> Int
  assert levels > 0, "need at least one level"
  levels * 16
end

SIZE = comptime table_size(0)

def main
  puts SIZE
end
```

```text
error[E0901]: `comptime` code failed: need at least one level
 --> main.wid:2:3
  |
2 |   assert levels > 0, "need at least one level"
  |   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ failed here
...
6 | SIZE = comptime table_size(0)
  |        ---------------------- while running this at compile time
  = see `wid explain E0901`
```

## How to fix

- Read the failure: it is the error the program would hit at run time, found
  earlier.
- Fix the input or the method. Here, `table_size` needs a positive count.
- To see intermediate values, `p` them inside the compile-time code; the output
  appears as a warning (E0909).

```wid
def table_size(levels: Int) -> Int
  assert levels > 0, "need at least one level"
  levels * 16
end

SIZE = comptime table_size(4)

def main
  puts SIZE
end
```

## In a macro

A macro can check its arguments with `assert` or `panic` while it runs, to
explain a bad call to its user:

```wid
macro def repeat(n: Int, body: Code) -> Code
  assert n > 0, "repeat needs a positive count"
  steps = [dynamic]Code.new
  for _i in 0...n
    steps << body
  end
  quote do
    #{steps}
  end
end

def main
  repeat 0, puts("hi")
end
```

```text
error[E0901]: the macro `repeat` failed: repeat needs a positive count
  --> main.wid:2:3
   |
 2 |   assert n > 0, "repeat needs a positive count"
   |   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ failed here
...
13 |   repeat 0, puts("hi")
   |   -------------------- while `repeat` ran for this call
   = see `wid explain E0901`
```

Pass arguments the macro accepts: here, `repeat 2, puts("hi")`.
