# E0604: symbol to document is private

<!-- command: doc . helper -->
<!-- fix-command: doc . helper -private -->

`wid doc` documents what code outside a package (or outside a type) can use,
so it leaves out declarations written `private`: a package's private methods,
constants, types and macros, and a type's private methods. This error says
the symbol path names one of those. The secondary label points at the
declaration.

## Example

`main.wid`:

```wid
# Adds one.
def add_one(x: Int) -> Int = helper(x)

private def helper(x: Int) -> Int = x + 1
```

Running `wid doc . helper` in its directory:

```text
error[E0604]: `helper` is private
 --> command line:1:11
  |
1 | wid doc . helper
  |           ^^^^^^ private declarations are left out of the documentation
 ::: main.wid:4:13
  |
4 | private def helper(x: Int) -> Int = x + 1
  |             ------ declared `private` here, which hides it outside its package
  = note: `wid doc` documents what code outside can use; `-private` shows the rest too
help: document private declarations too
  | wid doc . helper -private
  = see `wid explain E0604`
```

## How to fix

- Add `-private` to document private declarations too; it also lists them,
  marked `private`, in a package's overview.
- If code outside should use the declaration, remove `private` from it.

Running `wid doc . helper -private` shows the method.
