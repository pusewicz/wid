# E0903: compile-time code exceeded a limit

Compile-time code ran too long, nested calls too deeply, or used too much
memory. So that a mistake can't hang or exhaust the compiler, one `comptime`
evaluation may run 20 million steps, nest 256 calls and use 256 MiB. Real
compile-time work (tables, parsing an embedded file) fits easily, so hitting a
limit almost always means a loop that never ends or recursion that never stops.

Macros have the same limits for each run, and two of their own: the code a
macro generates may call macros only 64 deep (a macro whose code calls a
macro whose code calls a macro…), and one build expands at most 65,536 macro
calls. The error then shows the macro calls that led there, innermost first.

## Example

The recursion never reaches a base case:

```wid
def depth(n: Int) -> Int = depth(n + 1)

LEVELS = comptime depth(0)

def main
  puts LEVELS
end
```

```text
error[E0903]: `comptime` code stopped: calls nest more than 256 deep
 --> main.wid:1:28
  |
1 | def depth(n: Int) -> Int = depth(n + 1)
  |                            ^^^^^^^^^^^^ failed here
...
3 | LEVELS = comptime depth(0)
  |          ----------------- while running this at compile time
help: look for recursion that never stops
  = see `wid explain E0903`
```

## How to fix

Give the recursion (or the loop) a way to stop:

```wid
def depth(n: Int) -> Int = n >= 8 ? n : depth(n + 1)

LEVELS = comptime depth(0)

def main
  puts LEVELS
end
```

## A macro whose code calls itself

The code `countdown` generates calls `countdown` again, with nothing to stop
it:

```wid
macro def countdown(n: Int) -> Code
  quote do
    puts #{n}
    countdown(#{n - 1})
  end
end

def main
  countdown(3)
end
```

```text
error[E0903]: macro expansions nest more than 64 deep
 --> main.wid:4:5
  |
4 |     countdown(#{n - 1})
  |     ^^^^^^^^^^^^^^^^^^^ `countdown` would expand here, 65 expansions deep
 ::: main.wid:4:5
  |
4 |     countdown(#{n - 1})
  |     ------------------- `countdown` expands here (63 nested calls)
 ::: main.wid:9:3
  |
9 |   countdown(3)
  |   ------------ `countdown` expands here
  = note: the code a macro generates may call macros, but no deeper than this
help: look for a macro whose code calls a macro, maybe itself, with nothing to stop it
  = see `wid explain E0903`
```

Decide in the macro, while it runs, when to stop generating calls:

```wid
macro def countdown(n: Int) -> Code
  if n == 0
    return quote do
      puts "liftoff"
    end
  end
  quote do
    puts #{n}
    countdown(#{n - 1})
  end
end

def main
  countdown(3)
end
```
