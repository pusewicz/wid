# E0903: compile-time code exceeded a limit

Compile-time code ran too long, nested calls too deeply, or used too much
memory. So that a mistake can't hang or exhaust the compiler, one `comptime`
evaluation may run 20 million steps, nest 256 calls and use 256 MiB. Real
compile-time work (tables, parsing an embedded file) fits easily, so hitting a
limit almost always means a loop that never ends or recursion that never stops.

## Example

The recursion never reaches a base case:

```wid
def depth(n: Int) -> Int = depth(n + 1)

LEVELS = comptime depth(0)

def main
  puts LEVELS
end
```

```text
error[E0903]: `comptime` code stopped: calls nest more than 256 deep
 --> main.wid:1:5
  |
1 | def depth(n: Int) -> Int = depth(n + 1)
  |     ^^^^^ failed here
...
3 | LEVELS = comptime depth(0)
  |          ----------------- while running this at compile time
help: look for recursion that never stops
  = see `wid explain E0903`
```

## How to fix

Give the recursion (or the loop) a way to stop:

```wid
def depth(n: Int) -> Int = n >= 8 ? n : depth(n + 1)

LEVELS = comptime depth(0)

def main
  puts LEVELS
end
```
