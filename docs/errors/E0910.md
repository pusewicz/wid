# E0910: `quote` outside a `macro def`

A `quote do … end` builds code. It is how a `macro def` makes the code that
replaces each call of the macro: the macro runs while compiling and returns
the `quote`'s code, with its `#{}` splices filled in. Anywhere else there is
no macro to hand the code to, so a `quote` is an error.

Code that should just run is written out. Code that should be written for
you, in every place it is used, belongs in a macro.

## Example

```wid
def double(x: Int) -> Int
  quote do
    x * 2
  end
end

def main
  puts double(21)
end
```

```text
error[E0910]: `quote` only works inside a `macro def`
 --> main.wid:2:3
  |
2 |   quote do
  |   ^^^^^^^^ this is not inside a macro
  = note: a `quote` builds code for a macro to return, and the macro's caller gets that code in place of the call
help: write the code directly
  |   x * 2
  = see `wid explain E0910`
```

## How to fix

Write the code directly:

```wid
def double(x: Int) -> Int
  x * 2
end

def main
  puts double(21)
end
```

Or, to have the code written where each call is, make a macro that takes
the code it works on as a `Code` parameter and returns the `quote`:

```wid
macro def double(e: Code) -> Code
  quote do
    #{e} * 2
  end
end

def main
  puts double(21)
end
```
