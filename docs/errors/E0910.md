# E0910: `quote` outside a `macro def`

A `quote do … end` builds code. It is how a `macro def` makes the code that
replaces each call of the macro: the macro runs while compiling and returns
the `quote`'s code, with its `#{}` splices filled in. Anywhere else there is
no macro to hand the code to, so a `quote` is an error. A `def` that returns
`Code` was meant to be a macro: the error is then at the `def`, with the fix
that adds `macro`.

Code that should just run is written out. Code that should be written for
you, in every place it is used, belongs in a macro.

## Example

```wid
def double(x: Int) -> Int
  quote do
    x * 2
  end
end

def main
  puts double(21)
end
```

```text
error[E0910]: `quote` only works inside a `macro def`
 --> main.wid:2:3
  |
2 |   quote do
  |   ^^^^^^^^ this is not inside a macro
  = note: a `quote` builds code for a macro to return, and the macro's caller gets that code in place of the call
help: write the code directly
  |   x * 2
  = see `wid explain E0910`
```

## How to fix

Write the code directly:

```wid
def double(x: Int) -> Int
  x * 2
end

def main
  puts double(21)
end
```

Or, to have the code written where each call is, make a macro that takes
the code it works on as a `Code` parameter and returns the `quote`:

```wid
macro def double(e: Code) -> Code
  quote do
    #{e} * 2
  end
end

def main
  puts double(21)
end
```

## A `def` that returns `Code`

```wid
def make_const(name: Symbol) -> Code
  quote do
    #{name} = 1
  end
end

make_const :ONE

def main
  p ONE
end
```

```text
error[E0910]: `make_const` returns `Code`, but it is a `def`, not a `macro def`
 --> main.wid:1:1
  |
1 | def make_const(name: Symbol) -> Code
  | ^^^ `make_const` is declared as a method the program runs
2 |   quote do
  |   -------- a `quote` builds code only inside a `macro def`
...
7 | make_const :ONE
  | --------------- called among declarations, where only a macro call can stand
  = note: a `macro def` runs while compiling, and the code its `quote` builds replaces each call; `Code` exists only then
help: make `make_const` a macro
  | macro def make_const(name: Symbol) -> Code
  = see `wid explain E0910`
```

Only a macro takes and returns `Code`: it runs while compiling, and the code
its `quote` builds replaces each call. A `def` that returns `Code` is a
method the program would run, so it can't build code, and calling it among
declarations, where only a macro call can stand, does nothing. The error is
reported once, at the `def`, and the names the call would have declared
(`ONE`) aren't reported missing. A call of it in a method stands for code
that was never built, too: its arguments aren't checked against the `def`'s
parameters, and nothing is reported for the names its code would have
declared. Declare it with `macro def`:

```wid
macro def make_const(name: Symbol) -> Code
  quote do
    #{name} = 1
  end
end

make_const :ONE

def main
  p ONE
end
```
