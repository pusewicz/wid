# E0706: `types:` mapping does not match the C layout

`types:` lets a Wid type stand in for a C struct, like `[2]F32` for a
`Vector2` of two floats. Values are copied byte for byte at the boundary, so
the Wid type must have exactly the struct's size and alignment.

## Example

`shapes.h`:

```c
typedef struct Vec2 { float x, y; } Vec2;
float length(Vec2 v);
```

`main.wid`:

```wid
cimport "shapes.h", as: :shapes, types: {Vec2: [3]F32}

def main
  puts shapes.length([3.0, 4.0, 0.0])
end
```

```text
error[E0706]: `[3]F32` can't stand in for the C type `Vec2`
 --> main.wid:1:48
  |
1 | cimport "shapes.h", as: :shapes, types: {Vec2: [3]F32}
  |                                                ^^^^^^ `[3]F32` is 12 bytes, aligned to 4
  |                                          ---- `Vec2` is 8 bytes, aligned to 4
  = note: a mapped type is copied byte for byte, so both must have the same size and alignment
help: map `Vec2` to a Wid type with the same fields, or remove it from `types:`
  = see `wid explain E0706`
```

## How to fix

Map the struct to a Wid type with the same layout, or remove the mapping and
use the imported struct:

```wid
cimport "shapes.h", as: :shapes, types: {Vec2: [2]F32}

def main
  puts shapes.length([3.0, 4.0])
end
```
