# E0313: `case` does not cover every variant

A `case` over a tagged union or an enum must handle every variant or member,
whether it is used as a value or as a statement. Wid checks this at compile
time, so when a variant is added later, every `case` that needs a new branch
is reported. Inside each `when`, the subject is narrowed to that variant's
type.

A `case` over other values, such as numbers or strings, can't list every
value, so it needs an `else` when it is used as a value.

## Example

```wid
struct Circle
  radius: F32
end

struct Square
  side: F32
end

union Shape = Circle | Square

def area(s: Shape) -> F32
  case s
  when Circle then 3.14 * s.radius * s.radius
  end
end

def main
  shape: Shape = Square.new(side: 2.0)
  puts area(shape)
end
```

```text
error[E0313]: `case` does not handle Square
  --> main.wid:12:8
   |
12 |   case s
   |        ^ `Shape` has 2 variants
help: add `when Square` or an `else` branch
   = see `wid explain E0313`
```

## How to fix

- Add a `when` for each missing variant.
- Or add an `else` branch. It also hides variants added later, so prefer
  explicit branches when each variant needs its own handling.
- For an enum, list members as symbols: `when :north, :south then …`.

```wid
struct Circle
  radius: F32
end

struct Square
  side: F32
end

union Shape = Circle | Square

def area(s: Shape) -> F32
  case s
  when Circle then 3.14 * s.radius * s.radius
  when Square then s.side * s.side
  end
end

def main
  shape: Shape = Square.new(side: 2.0)
  puts area(shape)
end
```
