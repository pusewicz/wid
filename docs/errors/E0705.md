# E0705: C declaration was not imported

The header declares this name, but `cimport` could not turn it into Wid:

- a function-like macro (`#define SQUARE(x) ...`), which only C code can
  expand;
- a macro that doesn't expand to a value;
- a mutable global variable;
- a bit-field, or a field whose type Wid can't hold;
- a declaration that uses one of these, or a type Wid has no counterpart
  for, like `long double` or a `va_list` passed by value.

`wid cimport --dump header.h` prints the Wid view of a header, and lists
everything that was left out with the reason.

## Example

`util.h`:

```c
#define SQUARE(x) ((x) * (x))
int util_version(void);
```

`main.wid`:

```wid
cimport "util.h", as: :util

def main
  puts util.SQUARE(4)
end
```

```text
error[E0705]: `SQUARE` from `util.h` was not imported
 --> main.wid:4:13
  |
4 |   puts util.SQUARE(4)
  |             ^^^^^^ `SQUARE` is a function-like macro
  = note: C declares it at util.h:1
help: write a small C function in a `.c` file of the package that calls the macro, and declare it with `@[extern]`
  = see `wid explain E0705`
```

## How to fix

Wrap the declaration in a small C function in a `.c` file of the package, and
declare that function with `@[extern]`:

```c
// square.c
#include "util.h"
int util_square(int x) { return SQUARE(x); }
```

```wid
import "core:c", as: :C

@[extern("util_square")]
def square(x: C.int) -> C.int end

def main
  puts square(4)
end
```
