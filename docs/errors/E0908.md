# E0908: invalid `-define:` value

A `-define:name=value` flag gives a value that doesn't match the default of the
`config(:name, default)` that reads it. `config` parses the flag as the
default's type: `true`/`false` (or `1`/`0`) for a `Bool`, digits for an integer,
a number for a float, and any text for a string.

<!-- flags: -define:level=high -->

## Example

Built with `-define:level=high`:

```wid
LEVEL = config(:level, 1)

def main
  puts LEVEL
end
```

```text
error[E0908]: `-define:level=high` is not an integer
 --> main.wid:1:9
  |
1 | LEVEL = config(:level, 1)
  |         ^^^^^^^^^^^^^^^^^ `level` is read here, with a default of an integer
help: pass an integer, like `-define:level=1`, or drop the flag to use the default
  = see `wid explain E0908`
```

## How to fix

Pass a value of the default's type, like `-define:level=3`, or drop the flag to
use the default.

```wid
LEVEL = config(:level, 1)

def main
  puts LEVEL
end
```
