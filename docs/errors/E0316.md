# E0316: no matching overload

A call to an `overload` set fits none of its members, or fits several equally
well. A set such as `overload :half, :half_int, :half_f32` resolves each call
by the argument types:

- An argument of exactly the parameter's type is an exact match.
- An untyped literal (`5`, `2.5`) matches its default type (`Int`, `F64`)
  exactly and converts to any other number type that can hold it.
- A value converts to an optional of its type, a union that has it as a
  variant, or a slice of its element type.

The member with the most exact matches wins. Typed values never convert
between number types, so an `F64` argument fits neither an `Int` nor an `F32`
member. The error lists every member.

The same code reports a broken set declaration: a member that takes a block or
has `$` type parameters, or two members that take the same parameter types. It
also reports a method call that two `extend` blocks both define for the
receiver's type.

## Example

```wid
def half_int(x: Int) -> Int = x / 2
def half_f32(x: F32) -> F32 = x / 2.0

overload :half, :half_int, :half_f32

def main
  speed: F64 = 3.5
  puts half(speed)
end
```

```text
error[E0316]: no member of `half` takes (F64)
 --> main.wid:8:8
  |
8 |   puts half(speed)
  |        ^^^^^^^^^^^ called with (F64)
  = note: the members are `half_int(x: Int)`, `half_f32(x: F32)`
help: convert an argument with `.to(T)` so that one member's parameter types match
  = see `wid explain E0316`
```

When several members fit, the error suggests a conversion that picks one:

```wid
def pick_i32(x: I32) -> I32 = x
def pick_i64(x: I64) -> I64 = x

overload :pick, :pick_i32, :pick_i64

def main
  p pick(5)
end
```

```text
error[E0316]: several members of `pick` take (integer literal)
 --> main.wid:7:5
  |
7 |   p pick(5)
  |     ^^^^^^^ `pick_i32` and `pick_i64` fit equally well
  = note: the members are `pick_i32(x: I32)`, `pick_i64(x: I64)`
help: convert the argument to `I32`
  |   p pick(5.to(I32))
  = see `wid explain E0316`
```

## How to fix

- Convert the argument to a type the set takes: `half(speed.to(F32))`.
- Or add a member for the new type and list it in the set.
- If several members fit, convert an argument, or call the member you mean
  by its own name, such as `pick_i32(5)`.
- Keep members distinct: no two may take the same parameter types, and members
  cannot take blocks or `$` type parameters.
- If two `extend` blocks define the same method for one type, rename or remove
  one of them.

```wid
def half_int(x: Int) -> Int = x / 2
def half_f32(x: F32) -> F32 = x / 2.0
def half_f64(x: F64) -> F64 = x / 2.0

overload :half, :half_int, :half_f32, :half_f64

def main
  speed: F64 = 3.5
  puts half(speed)
end
```
