# E0909: compile-time code printed output

`puts`, `print` or `p` ran inside compile-time code. Compile-time code runs in
the compiler, so its output isn't part of the program; the compiler shows it as
this warning instead. That makes printing handy for debugging `comptime` code,
and the warning reminds you to remove it.

## Example

```wid
def table -> [4]Int
  t: [4]Int = {}
  for i in 0...4
    t[i] = i * 10
    p t[i]
  end
  t
end

TABLE = comptime table

def main
  p TABLE
end
```

```text
warning[E0909]: `comptime` code printed output
  --> main.wid:10:9
   |
10 | TABLE = comptime table
   |         ^^^^^^^^^^^^^^ this ran while compiling
   = note: it printed:
           0
           10
           20
           30
help: remove the printing once you are done debugging; compile-time output is not part of the program
```

## How to fix

Remove the printing once the code works:

```wid
def table -> [4]Int
  t: [4]Int = {}
  for i in 0...4
    t[i] = i * 10
  end
  t
end

TABLE = comptime table

def main
  p TABLE
end
```
