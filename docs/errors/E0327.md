# E0327: value is not a compile-time constant

Some positions need a value the compiler knows while it compiles the program,
but the code gives one that is only known at runtime, such as a variable, a
parameter or a method call. The compiler reports:

- an array length, as in `[n]F32`, that is not a constant integer;
- a package constant that calls a method without `comptime`, as in
  `LIMIT = width()` (the fix adds `comptime`), or whose value the compiler
  can't compute. A constant's value can be any expression the compiler
  evaluates: literals, other constants, struct literals, or a method call
  with `comptime`. A name in it that isn't defined is E0201, not this error;
- an enum member value that is not a constant integer;
- a variable of the surrounding method used inside `comptime` code, which runs
  before the variable has a value, or in the argument of a macro's parameter
  that isn't `Code`, `Symbol` or `Type`, which the macro receives as a value
  computed while compiling;
- a `comptime if` that binds a variable (`comptime if v = x`), or a field
  declared inside a `comptime if`.

## Example

```wid
def make_grid(n: Int)
  grid: [n]F32
  p grid
end

def main
  make_grid(8)
end
```

```text
error[E0327]: array length must be a compile-time integer
 --> main.wid:2:10
  |
1 | def make_grid(n: Int)
  |               ------ `n` is a variable, so its value is only known at run time
2 |   grid: [n]F32
  |          ^ not a constant integer
help: declare a package-level constant like `N = …` and write `[N]`, or allocate at run time with `alloc([]F32, n)`
  = see `wid explain E0327`
```

## How to fix

- Use a constant: `N = 8` at package level, then `grid: [N]F32`. A constant
  can also be computed by a method, with `N = comptime grid_size`.
- For a size known only at runtime, allocate a slice with
  `grid = alloc([]F32, n)` and `defer free(grid)`, or use `[dynamic]F32`.
- Give enum members literal values, or arithmetic on constants.

```wid
N = 8

def make_grid
  grid: [N]F32
  p grid
end

def main
  make_grid
end
```

## A variable passed to a macro's value parameter

```wid
macro def rep(n: Int) -> Code
  quote do
    #{n} * 2
  end
end

def main
  k = 3
  p rep(k)
end
```

```text
error[E0327]: the macro `rep` runs while compiling, so its `Int` parameter `n` needs a constant
 --> main.wid:9:9
  |
1 | macro def rep(n: Int) -> Code
  |               ------ `rep` receives `n`'s value while compiling
...
9 |   p rep(k)
  |         ^ `k` is a variable, which only has a value when the program runs
  = note: a macro's argument for a parameter that isn't `Code`, `Symbol` or `Type` is computed while compiling, like `comptime` code: it can use constants and literals, but not variables
help: to receive the expression itself, make the parameter `n: Code` and splice it with `#{n}`; the code then runs where `rep` is called
  = see `wid explain E0327`
```

A macro runs while compiling. Its `Code`, `Symbol` and `Type` parameters
receive the argument as written, but any other parameter receives its value,
computed then like `comptime` code, before `k` has one. Pass a constant, or
take the expression as `Code` and splice it, so it runs where the call is:

```wid
macro def rep(n: Code) -> Code
  quote do
    #{n} * 2
  end
end

def main
  k = 3
  p rep(k)
end
```
