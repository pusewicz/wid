# E0902: macro expansion failed

A macro call among declarations, like `attr_reader :hp` in a `struct` body,
cannot expand yet. Macros run where an expression or a statement goes, in
method bodies; a call in a `struct`, `enum`, `module` or `extend` body, which
would add declarations, is not implemented in this compiler version. (A macro
call at package level is reported as E0108.) `attr_reader`, `attr_writer`
and `attr_accessor` arrive with declaration-level expansion.

A macro that fails while it runs, in a method body, is E0901.

## Example

The macro writes a method, so the call stands among the struct's
declarations:

```wid
macro def describer(name: Symbol) -> Code
  quote do
    def describe -> String = "#{@#{name}}"
  end
end

struct Player
  hp: Int = 100
  describer :hp
end

def main
  p Player.new
end
```

```text
error[E0902]: `describer :hp` cannot expand: macro calls among declarations don't run yet
 --> main.wid:9:3
  |
9 |   describer :hp
  |   ^^^^^^^^^^^^^ a macro call inside a type
  = note: macro calls expand in method bodies; declaration-level expansion is not implemented yet
help: write the methods out, for example `def hp = @hp` for a reader
  = see `wid explain E0902`
```

## How to fix

Write out the declarations the macro would have made:

```wid
struct Player
  hp: Int = 100

  def describe -> String = "#{@hp}"
end

def main
  puts Player.new.describe
end
```
