# E0902: macro expansion failed

Earlier compiler versions reported E0902 for a macro call among declarations,
like `describer :hp` in a `struct` body, before such calls could expand.

No construct reports E0902 at the moment: macro calls expand in expressions,
as statements and among declarations (at package level and in `struct`,
`enum`, `module` and `extend` bodies). A macro that fails while it runs is
E0901, a spliced value that doesn't fit is E0911, an argument of the wrong
kind is E0912, and a declaration a macro can't generate is E0913. The code
stays reserved.

## How to fix

- If you see E0902 from an older compiler, update the compiler: macro calls
  among declarations expand now.
- If `docs/STATUS.md` lists declaration-level macro calls as done and you
  still get E0902, report it as a compiler bug.
