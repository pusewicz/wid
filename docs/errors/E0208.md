# E0208: missing `def main`

The package being built as a program has no `def main`. Execution starts at
`main`, which takes no parameters and returns nothing. The error points at
the start of the package's first file, because there is no line to blame.
The same code reports a `main` that exists but is not a method, such as an
`overload` set named `main`.

## Example

```wid
def helper
end
```

```text
error[E0208]: this package has no `def main`
 --> main.wid:1:1
  |
1 | def helper
  | ^ the program starts at `def main`
help: add an entry point
  | 
  | def main
  |   puts "hello"
  | end
  = see `wid explain E0208`
```

## How to fix

- Add `def main … end` to any file of the package.
- Make sure `main` is a plain method, not an `overload` set.
- If the package is a library, import it from a program instead of building
  it on its own.

```wid
def helper
  puts "helping"
end

def main
  helper
end
```
