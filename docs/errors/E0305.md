# E0305: value is not callable

The code calls something that is not a method or a proc. Only methods,
`overload` sets and values of a `proc(…)` type can be called with `(…)`. A
struct, enum, constant or plain value cannot. A struct value is built with
`Type.new(…)`, never by calling the type; for a generic struct the fix builds
the instance the call names, so `Local(Int)` becomes `Local(Int).new`. Wid
has no implicit multiplication, so `speed(2)` calls `speed` rather than
computing `speed * 2`. A local variable hides a method with the same name, so
after `double = 5`, `double(2)` tries to call the `Int`.

A field called like a method, `ball.radius()` or `@hp()` inside a method, is
reported here too, with a fix that reads it without `()`. A field that holds
a proc is called this way: `button.on_click(e)`, or `@on_click(e)` inside a
method, calls the proc.

The same code reports an `overload` set that lists something other than a
method, and arguments passed to `context`.

## Example

```wid
struct Ball
  radius: F32
end

def main
  ball = Ball(radius: 4.0)
  p ball
end
```

```text
error[E0305]: `Ball` is a struct, not a method
 --> main.wid:6:10
  |
6 |   ball = Ball(radius: 4.0)
  |          ^^^^ cannot be called
help: build a value with `new`
  |   ball = Ball.new(radius: 4.0)
  = see `wid explain E0305`
```

## How to fix

- Build struct values with `.new`: `Ball.new(radius: 4.0)`. It never
  allocates.
- If you meant arithmetic, write the operator: `speed * 2`.
- If a local variable has the same name as a method, rename one of them.
- To store something callable, use a proc:
  `double = ->(x: Int) -> Int { x * 2 }`, then `double(3)`.

```wid
struct Ball
  radius: F32
end

def main
  ball = Ball.new(radius: 4.0)
  p ball
end
```
