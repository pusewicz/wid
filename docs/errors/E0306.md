# E0306: condition is not a `Bool`

A condition has a type that is always truthy. Only `nil` and `false` are falsy
in Wid, so a number, string or struct used as a condition could never be
false. This applies to the conditions of `if`, `unless`, `elsif`, `while`,
`until` and `? :`, and to the operands of `!`, `&&` and `||`.

A condition must be a `Bool`, or a value that can be `nil`, such as an
optional or a union, which is tested for `nil`.

## Example

```wid
def main
  count = 3
  if count
    puts "never false"
  end
end
```

```text
error[E0306]: condition must be a `Bool`, found `Int`
 --> main.wid:3:6
  |
3 |   if count
  |      ^^^^^ this has type `Int`
  = note: only `nil` and `false` are falsy, so a number would always be true
help: compare it explicitly
  |   if count != 0
  = see `wid explain E0306`
```

## How to fix

- Compare explicitly: `count != 0`, `count > 0`.
- For strings and collections, test the size: `name.size > 0`.
- For an optional, test it directly (`if maybe`), or bind its value
  (`if v = maybe … end`).

```wid
def main
  count = 3
  if count != 0
    puts "count is #{count}"
  end
end
```
