# E0906: compile-time-only code runs at run time

A method that the program runs uses a value that exists only while compiling.
`Type` values (a type used as a value, like the `t` in `t.fields`) and
reflection (`T.fields`, `T.methods`) describe the program's types to
compile-time code; the built program has no such values. A method that uses
them, or calls a method that does, can only run inside `comptime`.

The error points at the run-time call and marks the compile-time-only use
inside the callee.

## Example

```wid
struct Point
  x: Int
  y: Int
end

def field_count(t: Type) -> Int
  t.fields.size
end

def main
  puts field_count(Point)
end
```

```text
error[E0906]: `field_count` works only at compile time
  --> main.wid:11:3
   |
 7 |   t.fields.size
   |     ------ reads a `Type`, which exists only while compiling
...
11 |   puts field_count(Point)
   |   ^^^^^^^^^^^^^^^^^^^^^^^ `main` calls it when the program runs
   = note: for type information at run time, use `type_info(x)`
help: call it while compiling instead, like `x = comptime field_count(…)`
   = see `wid explain E0906`
```

## How to fix

Run the method while compiling and use its result:

```wid
struct Point
  x: Int
  y: Int
end

def field_count(t: Type) -> Int
  t.fields.size
end

POINT_FIELDS = comptime field_count(Point)

def main
  puts POINT_FIELDS
end
```

For information about a value's type while the program runs, use
`type_info(x)`.
