# E0308: invalid conversion

`.to(T)` was asked for a conversion that does not exist. It converts between
numeric types, runes and enums, except that a float does not convert to an
enum. Other values have no implied numeric meaning: `true` is not `1`, a
`String` is not parsed, and a struct is not reinterpreted.

## Example

```wid
def main
  alive = true
  n = alive.to(Int)
  puts n
end
```

```text
error[E0308]: cannot convert `Bool` to `Int`
 --> main.wid:3:7
  |
3 |   n = alive.to(Int)
  |       ^^^^^^^^^^^^^ no conversion between these types
  = note: `.to(T)` converts between numbers, runes, enums and their distinct types, between pointer types, from arrays, slices and dynamic arrays to `[^]T`, and between `String`, `[]U8` and `CString` views
  = see `wid explain E0308`
```

## How to fix

- Spell out what the value means: `n = alive ? 1 : 0`.
- To turn a value into text, use `to_s` or interpolation: `"#{n}"`.
- If a float holds an enum value, convert it to an integer first:
  `x.to(Int).to(Dir)`.

```wid
def main
  alive = true
  n = alive ? 1 : 0
  puts n
end
```
