# E0326: unreachable code

Code follows a statement that always leaves the current block, such as
`return`, `break`, `next`, `panic` or `unreachable`, so it can never run. This
is a warning, not an error: the program still compiles. It usually points at a
mistake, such as an early `return` left over from debugging or an exit that
should have been conditional. Unreachable code is still type-checked, but it
never provides a method's or block's value.

## Example

```wid
def report(score: Int)
  puts score
  return
  puts "done"
end

def main
  report(3)
end
```

```text
warning[E0326]: unreachable code
 --> main.wid:4:3
  |
4 |   puts "done"
  |   ^^^^^^^^^^^ this never runs because the code above always leaves
help: remove it, or move it before the statement that leaves
```

## How to fix

- Delete the dead code, or the exit above it.
- If the exit should only happen sometimes, make it conditional:
  `return if score < 0`.
- When an `if` returns in every branch, code after it is unreachable too. Move
  that code into the branch that needs it.

```wid
def report(score: Int)
  puts score
  return if score < 0
  puts "done"
end

def main
  report(3)
end
```
