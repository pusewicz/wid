# E0907: cannot embed file

`embed("file")` couldn't read the file. `embed` reads a file when the program
is compiled and stores its bytes in the program, so the file must exist then.
Paths are relative to the package directory, and the path must be a string
known at compile time.

## Example

```wid
FONT = embed("assets/font.ttf")

def main
  puts FONT.size
end
```

```text
error[E0907]: cannot embed `assets/font.ttf`: the file does not exist
 --> main.wid:1:14
  |
1 | FONT = embed("assets/font.ttf")
  |              ^^^^^^^^^^^^^^^^^ looked for assets/font.ttf
  = note: paths are relative to the package directory
  = see `wid explain E0907`
```

## How to fix

Put the file at that path, or fix the path. When a file with a similar name
exists, the error suggests it.

```wid
def main
  puts "no font"
end
```
