# E0330: `?` method does not return `Bool`

A method whose name ends in `?` asks a yes-or-no question, as in Ruby
(`empty?`, `alive?`, `between?`), so its callers expect a `Bool`: they
write `if ship.alive?` or `ready = done? && !failed?`. Wid makes that a
rule. A `?` method declares `-> Bool`, whether it is a package-level
method, a method of a struct or enum, a type-level `def self.`, or a
method of a module or an `extend`, generic or not. The error points at the
return type, or at the name when there is none (and replaces E0310 for an
endless `def` without one). A method whose name ends in `!` has no such
rule.

A macro always returns `Code`, so its name can't end in `?` either: write
a method that returns `Bool` for the question, which may call the macro.

What the method was meant to return is unknown, so its calls report
nothing more, and its body is checked without a return type to match.

## Example

```wid
struct Ship
  hp: Int

  def alive? -> Int = @hp
end

def main
  ship = Ship.new(3)
  puts "still flying" if ship.alive?
end
```

```text
error[E0330]: `alive?` returns `Int`, but a method whose name ends in `?` must return `Bool`
 --> main.wid:4:17
  |
4 |   def alive? -> Int = @hp
  |                 ^^^ this should be `Bool`
  = note: a name ending in `?` asks a yes-or-no question, so callers expect a `Bool`
help: return a `Bool`
  |   def alive? -> Bool = @hp
help: or, if it isn't a yes-or-no question, drop the `?` and call it `alive`
  |   def alive -> Int = @hp

```

The first fix can be applied as it is when the body already gives a
`Bool` (a comparison, `true` or `false`, `!`, `&&` or `||` of such values,
or a call of another `?` method, in its value and every `return`).

## How to fix

- Make the method answer the question: declare `-> Bool` and return a
  `Bool`, like `@hp > 0`.
- If the method returns something else, like a count or a value that may
  be `nil`, drop the `?` from its name and from its callers: `hp_left`,
  `find_spawn`.

```wid
struct Ship
  hp: Int

  def alive? -> Bool = @hp > 0
end

def main
  ship = Ship.new(3)
  puts "still flying" if ship.alive?
end
```
