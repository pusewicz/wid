# E0709: cannot build for another target

`wid build`, `run` and `test` were given a `-target:` other than the machine
the compiler runs on. Wid builds programs with the host's C compiler, which
makes programs for the host only, so it can't produce an executable for another
operating system or architecture yet.

`-target:` still works with `wid check`: it sets `OS` and `ARCH`, so the
`comptime if` branches for that target are chosen and checked.

## Example

On an Apple Silicon Mac, `wid build main.wid -file -target:linux_amd64`
reports:

```wid
def main
  puts "hi"
end
```

```console
error[E0709]: cannot build for `linux_amd64` on `darwin_arm64`
  = note: Wid builds with the host C compiler, which makes programs for the host only
help: check the code for that target with `wid check -target:linux_amd64`, and build it on a linux_amd64 machine
  = see `wid explain E0709`
```

## How to fix

- Check the code for the other target with `wid check -target:linux_amd64`.
- Build on a machine of that target, without `-target:`.

```wid
def main
  puts "hi"
end
```
