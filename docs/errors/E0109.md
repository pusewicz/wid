# E0109: nested call needs parentheses

Parentheses are optional in two places only: zero-argument calls, and the
outermost call of a statement, as in `puts "hi"` or the value of an assignment
such as `total = double 4`. A call with arguments nested inside another
expression must use parentheses. Without them,
`puts double 4` could mean `puts(double(4))` or `puts(double, 4)`, and Wid does
not guess.

## Example

```wid
def double(x: Int) -> Int
  x * 2
end

def main
  puts double 4
end
```

```text
error[E0109]: `double` is called without parentheses inside another expression
 --> main.wid:6:8
  |
6 |   puts double 4
  |        ^^^^^^^^ this nested call needs parentheses
  = note: only the outermost call of a statement may omit parentheses
help: add parentheses
  |   puts double(4)
  = see `wid explain E0109`
```

## How to fix

- Add parentheses to every call with arguments that is itself an argument or an
  operand: `puts double(4)`, `total = double(4) + 1`.
- The outermost call may stay bare. `puts double(4)` and `puts(double(4))` are
  both fine.
- Zero-argument calls never need parentheses: `puts answer`.

```wid
def double(x: Int) -> Int
  x * 2
end

def main
  puts double(4)
end
```
