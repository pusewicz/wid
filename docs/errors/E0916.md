# E0916: compile-time code read a run-time value

Code that runs while compiling read a value the program only gets when it
starts. `ARGV`, the command-line arguments, is one: they are passed to the
built program, long after the compiler is done. Constants, `comptime` code
and macros all run while compiling, so none of them can read it, directly or
through a method they call.

## Example

```wid
VERBOSE = ARGV.include?("-v")

def main
  puts VERBOSE
end
```

```text
error[E0916]: `ARGV` only exists when the program runs
 --> main.wid:1:11
  |
1 | VERBOSE = ARGV.include?("-v")
  |           ^^^^ a constant's value is computed while compiling
  = note: the program sets `ARGV` when it starts, after compiling is over
help: read `ARGV` in a method, which runs with the program: replace the constant with one, like `def arg_count -> Int = ARGV.size`
  = see `wid explain E0916`
```

## How to fix

Read `ARGV` in a method, which runs with the program, and call it where the
constant was used. In `comptime` code, remove `comptime`:

```wid
def verbose? -> Bool = ARGV.include?("-v")

def main
  puts verbose?
end
```
