# E0707: opaque type used by value

An opaque struct, declared in C without its fields
(`typedef struct db_Conn db_Conn;`) or written `@[extern("…"), opaque]` in
Wid, has no known size. Only the library that defines it can create one, so
Wid code holds it through a pointer: a local, field, parameter or array
can't hold one by value.

## Example

`db.h`:

```c
typedef struct db_Conn db_Conn;
db_Conn *db_open(const char *path);
void db_close(db_Conn *conn);
```

`main.wid`:

```wid
cimport "db.h", as: :db, strip_prefix: "db_"

def main
  conn: db.Conn
  db.close(&conn)
end
```

```text
error[E0707]: `Conn` is opaque, so it can only be used through a pointer
 --> main.wid:4:9
  |
4 |   conn: db.Conn
  |         ^^^^^^^ this needs a whole `Conn`
  = note: C hides the fields and size of an opaque struct; only the library that defines it can create one
help: point at it instead
  |   conn: ^db.Conn
  = see `wid explain E0707`
```

## How to fix

Use a pointer, usually the one the library's constructor returns:

```wid
cimport "db.h", as: :db, strip_prefix: "db_"

def main
  guard conn = db.open("data.db") else
    panic "cannot open the database"
  end
  db.close(conn)
end
```
