# E0310: wrong return value

A `return` does not match the method's declared return type. Either a method
without `-> Type` returns a value, a method with a return type has a bare
`return`, or a method that returns several values returns a different number
of them. An endless method (`def f = expr`) needs a return type as well, or
its value is thrown away. `break` and `next` take a value only inside a
block, and only when the block has a result type.

## Example

```wid
def log(msg: String)
  puts msg
  return 1
end

def main
  log("x")
end
```

```text
error[E0310]: `log` does not return a value
 --> main.wid:3:10
  |
3 |   return 1
  |          ^ this value has nowhere to go
help: declare a return type with `-> Type`, or remove the value
  = see `wid explain E0310`
```

An endless method (`def f = expr`) is the same mistake: its value is thrown
away unless it declares a return type. The fix adds the value's type; in a
generic method, a type parameter's type is written as the parameter
(`def ident(v: $T) -> T = v`), and for `nil` or a symbol the fix leaves a
placeholder, since the value alone doesn't say which optional or enum it
is. What the method was meant to return is unknown, so its calls report
nothing more:

```wid
def sep = "/"

def main
  puts sep
end
```

```text
error[E0310]: `sep` has no return type, so its value is thrown away
 --> main.wid:1:11
  |
1 | def sep = "/"
  |           ^^^ this `String` is discarded
  = note: a method returns only what its return type declares; without `-> T`, it returns nothing
help: declare the return type
  | def sep -> String = "/"
  = see `wid explain E0310`
```

## How to fix

- If the method should produce a value, declare its type:
  `def log(msg: String) -> Int`.
- If it should not, remove the value, or the whole `return`.
- In a method with a return type, every `return` needs a value of that type.
- An endless method declares its type before the `=`: `def sep -> String = "/"`.

```wid
def log(msg: String)
  puts msg
end

def sep -> String = "/"

def main
  log("x")
  puts sep
end
```
