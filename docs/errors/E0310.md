# E0310: wrong return value

A `return` does not match the method's declared return type. Either a method
without `-> Type` returns a value, a method with a return type has a bare
`return`, or a method that returns several values returns a different number
of them. An endless method (`def f = expr`) needs a return type as well, or
its value is thrown away. `break` and `next` take a value only inside a
block, and only when the block has a result type.

## Example

```wid
def log(msg: String)
  puts msg
  return 1
end

def main
  log("x")
end
```

```text
error[E0310]: `log` does not return a value
 --> main.wid:3:10
  |
3 |   return 1
  |          ^ this value has nowhere to go
help: declare a return type with `-> Type`, or remove the value
  = see `wid explain E0310`
```

For an endless method, the message is
`` `answer` has no return type, so its value is thrown away ``, and the help
adds the type: `def answer -> Int = 42`.

## How to fix

- If the method should produce a value, declare its type:
  `def log(msg: String) -> Int`.
- If it should not, remove the value, or the whole `return`.
- In a method with a return type, every `return` needs a value of that type.
- An endless method declares its type before the `=`: `def answer -> Int = 42`.

```wid
def log(msg: String)
  puts msg
end

def main
  log("x")
end
```
