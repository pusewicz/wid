# E0104: invalid escape sequence

Inside a double-quoted string, `\` starts an escape, and the character after
it is not one Wid knows. Wid rejects unknown escapes instead of guessing what
they mean. A Windows path such as `"C:\games"` fails on `\g`.

## Example

```wid
def main
  puts "saved to C:\games"
end
```

```text
error[E0104]: `\g` is not an escape sequence
 --> main.wid:2:20
  |
2 |   puts "saved to C:\games"
  |                    ^^ not a valid escape
  = note: escapes: \n \t \r \0 \e \a \b \\ \" \' \# \xHH \u{XXXX}, and \ at the end of a line joins it with the next
help: for a literal backslash, write `\\`
  |   puts "saved to C:\\games"
  = see `wid explain E0104`
```

## How to fix

- Double the backslash to get a literal `\`: `"C:\\games"`.
- Use a single-quoted string. It only recognizes `\\` and `\'` and keeps every
  other backslash as written: `'C:\games'`.
- For a character by code, use `\xHH` with two hex digits below `80` (`\x41`),
  or `\u{…}` with a hex code point (`\u{1F600}`).
- Write `\#` for a literal `#` that would otherwise start an interpolation.

```wid
def main
  puts "saved to C:\\games"
end
```
