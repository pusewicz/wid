# E0302: wrong number of arguments

A call passes more arguments than the method has parameters, or leaves out a
parameter that has no default. Every parameter without a default must be
given, by position or by name. The error shows the definition so you can
compare.

The same code reports other count mismatches: a destructuring assignment
whose names and values differ in number (`a, b, c = pair`), a `yield` that
passes a different number of values than the method's block type declares, a
call through a proc, `.new` with more values than the struct has fields,
builtins such as `panic` and `alloc`, and `*` before an argument
(`f(*xs)`, `V.new(*xs)`): Wid has no argument spreading.

## Example

```wid
def area(w: Int, h: Int) -> Int
  w * h
end

def main
  puts area(3)
end
```

```text
error[E0302]: missing argument `h` in call to `area`
 --> main.wid:6:8
  |
1 | def area(w: Int, h: Int) -> Int
  |     ---- defined as `area(w: Int, h: Int)`
...
6 |   puts area(3)
  |        ^^^^^^^ needs `h`
  = see `wid explain E0302`
```

With too many arguments, the message reads
`` `area` takes 2 arguments, but 3 were given `` and points at the extras.

## How to fix

- Pass every required argument: `area(3, 4)`.
- Remove extra arguments.
- If a parameter usually has the same value, give it a default in the
  definition: `def area(w: Int, h: Int = 1) -> Int`.
- Name the arguments to make long calls easier to check: `area(w: 3, h: 4)`.

```wid
def area(w: Int, h: Int) -> Int
  w * h
end

def main
  puts area(3, 4)
end
```

## `*` before an argument

```wid
struct V
  x: Int
  y: Int
end

def main
  xs = [1, 2]
  v = V.new(*xs)
  p v.y
end
```

```text
error[E0302]: Wid has no argument spreading
 --> main.wid:8:14
  |
8 |   v = V.new(*xs)
  |              ^^ `*` cannot spread a collection into arguments
  = note: `V.new` takes a value for each field, by position or by name
help: pass the elements one by one
  |   v = V.new(xs[0], xs[1])
  = see `wid explain E0302`
```

In Ruby, `*xs` spreads a collection's elements over a method's parameters.
Wid has no argument spreading: every method takes a fixed number of
arguments, and `T.new` a value for each field, so how many values a call
passes is always visible where it is written. The collection fills nothing,
and nothing after it is reported. Pass the elements one by one, as the fix
does for `.new` (it indexes an array, slice or dynamic array for each field
left), or give a method that takes any number of values a slice parameter
(`xs: []Int`), which an array converts to:

```wid
struct V
  x: Int
  y: Int
end

def main
  xs = [1, 2]
  v = V.new(xs[0], xs[1])
  p v.y
end
```
