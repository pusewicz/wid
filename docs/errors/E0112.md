# E0112: misused `*` parameter

A parameter written `*names: T` is variadic: it collects the remaining
positional arguments, zero or more, into a `[]T`. Only a `macro def` can take
one, so that a macro reads like Ruby, as in `attr_reader :hp, :mana`. Methods
and procs take a fixed number of arguments: give them a `[]T` parameter and
pass an array literal, which is just as short and makes the slice visible.

Inside a `macro def`, the `*` parameter must be the last parameter, because
it takes every positional argument after the ones before it, and it can't
have a default: without arguments it is an empty slice.

## Example

```wid
def sum(*xs: Int) -> Int
  total = 0
  for x in xs
    total += x
  end
  total
end

def main
  puts sum(1, 2, 3)
end
```

```text
error[E0112]: only a `macro def` can take a `*` parameter
 --> main.wid:1:9
  |
1 | def sum(*xs: Int) -> Int
  |         ^^^^^^^^ this would collect the remaining arguments
  = note: a method takes a fixed number of arguments; a `*` parameter is for macros, like `attr_reader :hp, :mana`
help: take a slice instead, and pass an array literal: `sum([a, b, c])`
  | def sum(xs: []Int) -> Int
  = see `wid explain E0112`
```

## How to fix

- In a method or proc, take a slice (`xs: []Int`) and pass an array literal:
  `sum([1, 2, 3])`.
- In a `macro def`, move the `*` parameter to the end, and remove its
  default.

```wid
def sum(xs: []Int) -> Int
  total = 0
  for x in xs
    total += x
  end
  total
end

def main
  puts sum([1, 2, 3])
end
```
