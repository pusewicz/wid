# E0206: package not found

An `import` names a package the compiler cannot find. A package is a
directory of `.wid` files:

- `"./…"` and `"../…"` look relative to the importing package's directory;
- `"core:…"` and `"vendor:…"` look in Wid's own collections;
- `"name:…"` looks in a collection defined with `-collection:name=path`.

The import fails when the directory doesn't exist, when it has no `.wid`
files, or when the collection is unknown. If a sibling directory has a
similar name, the help suggests it. The same code reports a build target that
is not a package: a missing directory, a directory without `.wid` files, or a
single `.wid` file passed without `-file`. With `-file`, it reports a target
that is not a file, pointing into the command line: no file named
(`wid check -file`), a missing file, or a directory.

## Example

`physics/body.wid`:

```wid
def step(x: F32, v: F32, dt: F32) -> F32 = x + v * dt
```

`main.wid`:

```wid
import "./phyiscs"

def main
  x: F32 = 0.0
  puts phyiscs.step(x, 2.0, 0.5)
end
```

```text
error[E0206]: package `./phyiscs` not found
 --> main.wid:1:8
  |
1 | import "./phyiscs"
  |        ^^^^^^^^^^^ no directory at `phyiscs`
  = see `wid explain E0206`
```

The E0201 follows from the failed import and goes away with it.

## How to fix

- Fix the path. The help suggests a sibling directory with a similar name.
- Relative paths are resolved from the importing package's directory, not
  from the directory you run `wid` in.
- For a custom collection prefix, pass `-collection:name=path/to/dir`.
- Make sure the directory has at least one `.wid` file. Files ending in
  `_test.wid` don't count.
- `wid check`, `wid build` and `wid run` take a directory. To use a single
  file, add `-file`: `wid run main.wid -file`.
- With `-file`, name an existing `.wid` file before the flag. The help
  suggests a file with a similar name, or the only `.wid` file in the
  directory; for a package directory, it drops `-file`.

```wid
import "./physics"

def main
  x: F32 = 0.0
  puts physics.step(x, 2.0, 0.5)
end
```
