# E0321: cannot bind a temporary by reference

A by-reference binding needs storage that already exists: a variable, a field
or an element of one. `for &x in …` and a block parameter `|&x|` give a
pointer into that storage, so writes through `x` change the original. A
temporary, such as an array literal or a value returned by a call, is a copy
that disappears at the end of the statement, so writes through the reference
would be lost.

The same code reports the other by-reference bindings that have nothing to
point into:

- `|&x|` when the method yields a temporary, such as `yield 1 + 2`;
- `for &c in some_string`, because strings are immutable;
- `for &k, v in some_map`, because map entries are bound by value.

## Example

```wid
def main
  for &n in [1, 2, 3]
    n *= 2
  end
end
```

```text
error[E0321]: cannot bind elements of a temporary by reference
 --> main.wid:2:13
  |
2 |   for &n in [1, 2, 3]
  |             ^^^^^^^^^ this value is a temporary copy
help: store it in a variable first, or drop the `&`
  = see `wid explain E0321`
```

## How to fix

- Store the value in a variable, then bind into it: `nums = [1, 2, 3]`, then
  `for &n in nums`.
- If you only read the elements, bind by value: `for n in [1, 2, 3]`.
- For a block, bind by value (`|x|`), or make the method yield a variable or
  element.
- Change map values with `m[key] = value` inside a by-value loop.

```wid
def main
  nums = [1, 2, 3]
  for &n in nums
    n *= 2
  end
  p nums
end
```
