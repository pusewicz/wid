# E0110: invalid symbol literal

A symbol is written with quotes. A symbol is a compile-time name: `:`
followed directly by an identifier (`:hp`, `:empty?`, `:save!`, `:x=`) or
by an operator name (`:+`, `:<=>`, `:[]`, `:[]=`). Ruby's quoted symbols such
as `:"debug_draw"` do not exist in Wid, because a symbol must name a method,
an option or a name a macro splices, known at compile time.

When the quoted text is a plain name, the fix removes the quotes. Other text,
like `:"two words"`, cannot be a symbol at all; use a `String` for it.

## Example

```wid
DEBUG_DRAW = config(:"debug_draw", false)

def main
  p DEBUG_DRAW
end
```

```text
error[E0110]: symbols are written without quotes
 --> main.wid:1:21
  |
1 | DEBUG_DRAW = config(:"debug_draw", false)
  |                     ^^^^^^^^^^^^^ a quoted symbol
help: remove the quotes
  | DEBUG_DRAW = config(:debug_draw, false)
  = see `wid explain E0110`
```

## How to fix

- Write the name with no quotes and no space after the colon: `:debug_draw`.
- Symbols cannot be built from runtime data. A macro can make one from a
  string while compiling, with `"text".to_sym`.
- An enum member is not a symbol: write it `.North` where its enum is
  expected (`heading: Dir = .North`).

```wid
DEBUG_DRAW = config(:debug_draw, false)

def main
  p DEBUG_DRAW
end
```
