# E0110: invalid symbol literal

A symbol is written with quotes. A symbol is a compile-time name: `:`
followed directly by an identifier (`:north`, `:empty?`, `:save!`, `:x=`) or
by an operator name (`:+`, `:<=>`, `:[]`, `:[]=`). Ruby's quoted symbols such
as `:"north"` do not exist in Wid, because a symbol must name an enum member, a
method or an option that is known at compile time.

When the quoted text is a plain name, the fix removes the quotes. Other text,
like `:"two words"`, cannot be a symbol at all; use a `String` for it.

## Example

```wid
enum Dir
  north
  south
end

def main
  heading: Dir = :"north"
  p heading
end
```

```text
error[E0110]: symbols are written without quotes
 --> main.wid:7:18
  |
7 |   heading: Dir = :"north"
  |                  ^^^^^^^^ a quoted symbol
help: remove the quotes
  |   heading: Dir = :north
  = see `wid explain E0110`
```

## How to fix

- Write the name with no quotes and no space after the colon: `:north`.
- Symbols cannot be built from runtime data. To pick an enum member from a
  number, convert it with `.to(Dir)`, or match it with `case`.

```wid
enum Dir
  north
  south
end

def main
  heading: Dir = :north
  p heading
end
```
