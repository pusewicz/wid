# E0205: item is private

The code uses a declaration marked `private` from a place that cannot see it.
A `private` package-level method or constant can only be used inside its own
package (its directory), so `pkg.name` from another package is an error. A
`private` method of a type can only be called from methods of that type,
including methods mixed in with `include` and added with `extend`.

## Example

`physics/body.wid`:

```wid
private def integrate(x: F32, v: F32, dt: F32) -> F32 = x + v * dt

def step(x: F32, v: F32, dt: F32) -> F32 = integrate(x, v, dt)
```

`main.wid`:

```wid
import "./physics"

def main
  x: F32 = 0.0
  puts physics.integrate(x, 2.0, 0.5)
end
```

```text
error[E0205]: `integrate` is private to package `physics`
 --> main.wid:5:16
  |
5 |   puts physics.integrate(x, 2.0, 0.5)
  |                ^^^^^^^^^ not visible from here
 ::: physics/body.wid:1:13
  |
1 | private def integrate(x: F32, v: F32, dt: F32) -> F32 = x + v * dt
  |             --------- declared `private` here
help: use a public method of `physics` instead, or remove `private` from the declaration
  = see `wid explain E0205`
```

## How to fix

- Use the package's public API. Here `physics.step` wraps `integrate`.
- If the item is meant to be used from outside, remove `private` from its
  declaration.
- For a private method, call a public method of the type that uses it.

```wid
import "./physics"

def main
  x: F32 = 0.0
  puts physics.step(x, 2.0, 0.5)
end
```

## Private methods

A private method called from outside its type:

```wid
struct Account
  balance: Int

  def deposit(n: Int)
    @balance += n
    audit
  end

  private def audit
    puts "balance is now #{@balance}"
  end
end

def main
  a = Account.new(0)
  a.audit
end
```

```text
error[E0205]: `audit` is private to `Account`
  --> main.wid:16:5
   |
 9 |   private def audit
   |               ----- declared `private` here
...
16 |   a.audit
   |     ^^^^^ called from outside `Account`
help: call a public method instead, or remove `private` from the declaration
   = see `wid explain E0205`
```

Call `a.deposit(10)` instead, which runs `audit` from inside the type.
